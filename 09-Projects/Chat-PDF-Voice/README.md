\# 📄 Chat with PDF + Voice 🎤



> Upload any PDF and have an intelligent conversation with it — with voice support!



\## ✨ Features



\- 📁 Upload any PDF document

\- 🤖 AI-powered question answering

\- 🔊 Voice output for every answer

\- 💬 Full chat history

\- 🧠 RAG (Retrieval Augmented Generation)

\- 🌙 Dark professional UI



\## 🏗️ How It Works



```

PDF Upload

&#x20;   ↓

Text extracted + chunked

&#x20;   ↓

ChromaDB vector storage

&#x20;   ↓

User asks question

&#x20;   ↓

AI finds relevant chunks

&#x20;   ↓

Answer generated + spoken! 🔊

```



\## 🛠️ Tech Stack



| Technology | Purpose |

|---|---|

| LangChain | AI Pipeline |

| ChromaDB | Vector Database |

| OpenRouter | Free AI Model |

| Streamlit | UI |

| gTTS | Voice Output |

| PyPDF | PDF Reading |



\## 🚀 Getting Started



\### 1. Clone repo

```bash

git clone https://github.com/emanfatima3456-wq/AI-Automation-Journey.git

cd 09-Projects/Chat-PDF-Voice

```



\### 2. Create virtual environment

```bash

python -m venv pdf\_env

pdf\_env\\Scripts\\activate

```



\### 3. Install dependencies

```bash

pip install -r requirements.txt

```



\### 4. Setup .env

```

OPENROUTER\_API\_KEY=your\_key\_here

```



\### 5. Run app

```bash

streamlit run app.py

```
