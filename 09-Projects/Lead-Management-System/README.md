# 💼 AI Lead Management System

> Automatically capture, analyze and manage business leads using AI!

---

## 🎯 Problem It Solves

Businesses receive hundreds of leads daily. Manually reading, 
analyzing and saving each lead wastes hours of time and money.

This system automates the entire lead management process in seconds!

---

## ⚡ How It Works
Customer fills form
↓
Webhook captures data
↓
AI analyzes lead quality
↓
Auto-saved to Google Sheets
↓
Real-time Dashboard
---

## 🚀 Features

| Feature | Description |
|---------|-------------|
| 📋 Smart Form | Professional lead capture form |
| ⚡ Instant Capture | Webhook receives data in milliseconds |
| 🤖 AI Analysis | Automatically scores lead quality |
| 📊 Google Sheets | Auto-saves all lead data |
| 📈 Dashboard | Real-time Streamlit dashboard |

---

## 🛠️ Tech Stack

- **n8n** — No-code automation workflow
- **Cohere AI** — Lead analysis and scoring
- **Google Sheets** — Data storage
- **Streamlit** — Real-time dashboard
- **HTML/CSS** — Professional frontend form

## ⚙️ How To Run

**1. Clone the repository**
```bash
git clone https://github.com/emanfatima3456-wq/AI-Automation-Journey.git
cd 09-Projects/Lead-Management-System
```

**2. Install dependencies**
```bash
pip install streamlit pandas
```

**3. Run dashboard**
```bash
streamlit run app.py
```

**4. Open form**
Open index.html in browser
